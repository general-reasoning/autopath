\section{Overview}

The \texttt{Hydro} datablock provides a flexible framework for latent-to-image decoders. It is designed to invert feature extractors (e.g., GigaPath) by mapping their embeddings back to the original image space. The system supports multiple architectural versions, dispatched via the \texttt{version} parameter in the model configuration.

\section{Model\_0: Deconvolutional Decoder}

\texttt{Model\_0} is the baseline architecture, using progressive upsampling to reconstruct $N \times N$ RGB images from $K$-dimensional latent vectors.

\subsection{Architectural Improvements to Combat Blur}

To address the blurriness observed in \texttt{Model\_0} outputs, several optional components can be enabled. These features prioritize the preservation and enhancement of high-frequency information.

\subsubsection{Spatial Attention Gates}
The \texttt{SpatialAttentionGate} identifies and emphasizes salient spatial features (e.g., edges and textures) while suppressing redundant background information.

By applying a learned spatial mask $\mathbf{M}$, the model focuses its representational capacity on sharp edge transitions, effectively reducing the ``halos'' and washed-out textures typical of standard deconvolutional decoders.

\subsubsection{Feature Modulation}
Feature modulation allows the global latent vector $\mathbf{z}$ to dynamically scale the intensity of intermediate feature maps. This provides a mechanism for the latent representation to globally influence spatial details at every upsampling stage.

This global conditioning ensures that the reconstructed image maintains sharpening consistency across different scales, as the latent vector can ``boost'' specific frequency components needed for a sharp reconstruction.

\subsubsection{Residual Upsampling}
Residual upsampling incorporates long-range skip connections around the upsampling layers. This allows the network to learn only the residual difference needed to reach the next resolution, facilitating better gradient flow and preserving high-frequency details from lower spatial resolutions.

\section{Model\_1: Vision Transformer (ViT) Decoder}

\texttt{Model\_1} adopts a transformer-based architecture to model long-range dependencies and produce sharper reconstructions by operating on a tokenized representation of the image.

\subsection{Architecture Overview}

The architecture follows a ``latent token to patch'' approach:

\subsubsection{Tokenization and Projection}
The latent vector $\mathbf{z}$ is projected into a sequence of $M = (N/p)^2$ tokens, where $p$ is the patch size (e.g., 16).
\[
    \mathbf{z} \xrightarrow{\text{MLP}} \mathbf{T} \in \mathbb{R}^{M \times D}
\]
Learnable 2D positional embeddings are added to provide spatial context to the transformer.

\subsubsection{Transformer Backbone}
A series of $L$ standard Transformer blocks (Multi-Head Self-Attention + MLP) process the token sequence. This allows information to propagate globally across the image grid.

\subsubsection{Reconstruction Head}
Each token $\mathbf{t}_i \in \mathbb{R}^D$ is projected to a patch $\mathbf{P}_i \in \mathbb{R}^{3 \times p \times p}$ using a linear layer. The patches are then rearranged to form the final image $\mathbf{I} \in \mathbb{R}^{3 \times N \times N}$.

\section{Loss Functions}

Reconstruction quality is improved by incorporating perceptual metrics:
\[
    \mathcal{L} = \begin{cases}
        \frac{1}{3N^2}\|\hat{\mathbf{I}} - \mathbf{I}^*\|_2^2 & \text{if \texttt{loss\_type} = ``mse''} \\[4pt]
        \frac{1}{3N^2}\|\hat{\mathbf{I}} - \mathbf{I}^*\|_1   & \text{if \texttt{loss\_type} = ``l1''} \\[4pt]
        \text{LPIPS}(\hat{\mathbf{I}}, \mathbf{I}^*) & \text{if \texttt{loss\_type} = ``lpips''}
    \end{cases}
\]
The \textbf{LPIPS} (Learned Perceptual Image Patch Similarity) loss compares deep features from a pre-trained network (e.g., VGG) and is highly effective at reducing blur by penalizing differences in perceptual content rather than raw pixel values.
