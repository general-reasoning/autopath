\section{Overview}

The \texttt{Hydro} datablock provides a flexible framework for latent-to-image decoders. It is designed to invert feature extractors (e.g., GigaPath) by mapping their embeddings back to the original image space. 

\subsection{Large-scale System Architecture}
In the context of the overall pipeline, \texttt{Hydro} serves as the generative component that transforms compressed semantic embeddings into spatial reconstructions. The global latent vector $\mathbf{z}$ is the primary interface between the large-scale encoder and the decoder.

The latent vector $\mathbf{z}$ is produced by a fixed (or fine-tuned) backbone that summarizes the semantic content of a histology slide or patch. This vector provides the global context used by \texttt{Hydro} features like Feature Modulation to inform the progressive upsampling process.

The \texttt{SpatialAttentionGate} identifies and emphasizes salient spatial features (e.g., edges and textures). It is situated at the end of each upsampling stage to refine the newly generated spatial details.

The gate receives the upsampled feature map $\mathbf{x} \in \mathbb{R}^{C \times H \times W}$. In its enhanced version, it employs $3\times3$ convolutions to capture better spatial context when computing the mask, effectively identifying sharp transitions like edges and textures which are then selectively amplified.

The mask generator sub-network learns a **pixelwise** spatial mask $\mathbf{M}$ where each value $\in [0, 1]$. This single-channel mask is shared across all $C$ channels. The output is computed via the Hadamard product (element-wise multiplication $\odot$) with broadcasting:
\[
    \mathbf{y}_{c,h,w} = \mathbf{x}_{c,h,w} \times \mathbf{M}_{1,h,w}
\]
By focusing representational capacity on these spatially-encoded transitions, SAG effectively reduces smoothing artifacts.

\subsubsection{Residual Architectures}
Two distinct types of residual connections are available to improve gradient flow and preserve signal fidelity.

\paragraph{Upsampling Residuals (\texttt{cnn\_use\_residual\_upsampling})}
This resolution-skipping connection operates \textbf{across} an upsampling block. It provides a direct path for low-frequency content by upsampling the previous stage's feature map (typically via bilinear interpolation) and adding it to the current stage's output. 

\paragraph{Internal Residuals (\texttt{cnn\_use\_residual})}
This connection operates \textbf{within} a single \texttt{ConvBlock} at a constant resolution. It adds the block's input directly to its output ($y = f(x) + x$), helping gradients propagate through deep stacks of convolutions without attenuation or blurring.

\subsubsection{Pixel-Shuffle Upsampling (\texttt{cnn\_use\_pixel\_shuffle})}
Instead of using bilinear interpolation or standard transposed convolutions (deconvolution), the model can be configured to use \textbf{Pixel-Shuffle} (Depth-to-Space) upsampling. This technique rearranges channels into higher spatial resolution ($2\times \uparrow$), which often results in significantly sharper edges as it avoids the interpolation artifacts typical of standard upsampling kernels.

\section{Model\_ViT: Vision Transformer (ViT) Decoder}

\texttt{Model\_ViT} adopts a transformer-based architecture to model long-range dependencies and produce sharper reconstructions by operating on a tokenized representation of the image.

\subsubsection{Tokenization and Projection}
The latent vector $\mathbf{z}$ is projected into a sequence of $M = (N/p)^2$ tokens, where $p$ is the patch size (e.g., 16).
\[
    \mathbf{z} \xrightarrow{\text{MLP}} \mathbf{T} \in \mathbb{R}^{M \times D}
\]
Learnable 2D positional embeddings are added to provide spatial context to the transformer.

\subsubsection{Transformer Backbone}
A series of $L$ standard Transformer blocks (Multi-Head Self-Attention + MLP) process the token sequence. This allows information to propagate globally across the image grid.

\section{Sharpness Enhancement Design}

Several model-independent mechanisms are provided to improve the visual fidelity of reconstructions, specifically targeting the suppression of blur.

\subsection{Perceptual Scaling}
The \texttt{lpips} loss relies on a pre-trained VGG feature extractor. Since the decoder typically outputs pixel values in the range $[0, 255]$, while VGG expects inputs normalized to $[0, 1]$, an internal scaling factor is applied:
\[
    \hat{\mathbf{I}}_{\text{perceptual}} = \frac{\hat{\mathbf{I}}}{255.0}
\]
This ensuring that the perceptual gradients are correctly scaled relative to the learned weights.

\subsection{Gradient Penalization (\texttt{grad})}
To explicitly reward the preservation of high-frequency edges, the model can minimize the $L_1$ distance between the spatial gradients of the predicted and target images:
\[
    \mathcal{L}_{\text{grad}} = \|\nabla_x\hat{\mathbf{I}} - \nabla_x\mathbf{I}^*\|_1 + \|\nabla_y\hat{\mathbf{I}} - \nabla_y\mathbf{I}^*\|_1
\]
where $\nabla$ represents the Sobel operator (or standard finite difference). Unlike MSE, which tends to average out high-frequency noise and produce blurry boundaries, Gradient Loss forces the model to match the local contrast transitions.

\subsection{Structural Similarity Index (\texttt{ssim})}
The Structural Similarity Index (SSIM) is used as a differentiable loss function to capture perceived changes in structural information, luminance, and contrast. Unlike pixel-wise losses (MSE/L1), SSIM is insensitive to uniform changes in brightness and better matches human visual perception of similarity:
\[
    \text{SSIM}(\mathbf{x}, \mathbf{y}) = \frac{(2\mu_x\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)}
\]
The model minimizes $1 - \text{SSIM}$, promoting the reconstruction of realistic textures and structural patterns. 

The SSIM loss is typically combined with a pixel-wise companion loss (e.g., $L_1$) to ensure intensity consistency and provide more stable gradients:
\[
    \mathcal{L}_{\text{total}} = (1 - \alpha)\mathcal{L}_{\text{ssim}} + \alpha\mathcal{L}_{\text{comp}}
\]
where $\alpha$ is the \texttt{ssim\_companion\_weight} and $\mathcal{L}_{\text{comp}}$ is the value of \texttt{ssim\_companion\_loss} (\texttt{l1} or \texttt{mse}).
