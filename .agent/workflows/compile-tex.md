To compile a `.tex` file into a PDF using the `tectonic` installation in the `autopath` conda environment:

// turbo
1. Run the compilation command:
```bash
/home/t-9dkarp/miniconda3/envs/autopath/bin/tectonic [path/to/file.tex]
```

The PDF will be generated in the same directory as the source `.tex` file.
